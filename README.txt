Что делает программа
====================

Эта программа считает зону автомобильной доступности от одной заданной точки.
Вы вводите широту, долготу и лимит, например 100 км или 120 минут, а программа
показывает, по каким дорогам можно доехать от этой точки в пределах заданного лимита.

Программа не строит маршрут "город A -> город B".
Она считает именно доступность от одной исходной точки:

одна точка -> лимит -> достижимые дороги вокруг этой точки


Как программа работает сейчас
=============================

Сейчас в программе два отдельных шага.

1. "Сгенерировать карту"

Это базовый и быстрый режим.
Он делает только расчет дорожной доступности и сохраняет HTML-карту.
На этом шаге программа:

- ищет дороги рядом с заданной точкой;
- строит дорожный граф;
- считает, куда можно доехать по дорогам;
- сохраняет карту routes_map.html.

На этом этапе программа НЕ ищет население и НЕ делает запросы в Wikidata.


2. "Найти население в зоне"

Это отдельный, более тяжелый шаг.
Он запускается только после того, как карта уже построена.

На этом шаге программа:

- берет уже готовую рассчитанную зону доступности;
- ищет населенные пункты рядом с этой зоной;
- отбирает только те населенные пункты, которые действительно попадают в достижимую зону;
- пытается получить население:
  сначала из локальных данных, если там есть поле population;
  потом из локального кэша population_cache.json;
  и только если данных нет, делает запросы в Wikidata;
- добавляет в routes_map.html верхний итог и нижнюю таблицу.


Какие данные нужны
==================

Программа использует данные Geofabrik на основе OpenStreetMap.
Поддерживаются файлы:

- .shp
- .gpkg

Если используется shapefile, выбирать нужно файл дорог:

gis_osm_roads_free_1.shp

Файл .dbf отдельно выбирать не нужно. Он лежит рядом с .shp и содержит таблицу
атрибутов дорог.

Если используются архивы .gpkg.zip с сайта Geofabrik, их нужно сначала распаковать.
Внутри должен лежать файл вида:

ural-fed-district.gpkg
volga-fed-district.gpkg
central-fed-district.gpkg


Как работать по всей России
===========================

Для расчета по разным городам России удобнее сложить все распакованные .gpkg файлы
в одну папку и выбрать в программе кнопку "Папка РФ".

В этом режиме программа сама проходит по файлам в выбранной папке и берет из них
дороги рядом с заданной точкой.

Если точка или лимит находятся рядом с границей федеральных округов, программа может
взять данные сразу из нескольких файлов Geofabrik.


Что означает лимит
==================

Лимит в программе - это не круг по прямой линии на карте.
Это расстояние по дорожной сети или примерное время в пути по дорожной сети.

Например:

- 100 км = сколько можно проехать по дорогам на 100 км;
- 120 минут = сколько можно доехать по дорогам примерно за 2 часа.

Если в какую-то сторону дорог нет, программа не будет рисовать туда доступность.


Что означают логи по населённым пунктам
=======================================

Пример:

Карта сохранена: ...
Время выполнения: 10.7 сек.
Старт поиска населенных пунктов по готовой зоне доступности.
Найдены населенные пункты в файле: far-eastern-fed-district.gpkg (99 строк)
Населенных пунктов в достижимой зоне найдено: 37

Расшифровка простыми словами:

- "99 строк" означает, что в выбранном файле Geofabrik программа нашла 99 объектов
  населенных пунктов в рабочей области поиска рядом с вашей точкой и лимитом.
  Это еще не итоговая выборка.

- "37" означает, что после дополнительной проверки программа оставила только 37
  населенных пунктов, которые реально попали в достижимую зону по дорогам.

То есть в вашем примере логика именно такая:

1. программа прочитала из файла Geofabrik 99 объектов населенных пунктов рядом
   с вашей точкой и лимитом;
2. потом отфильтровала их по уже рассчитанной зоне доступности;
3. в итоге оставила 37 подходящих населенных пунктов.

Если ниже в логах появляется строка вида:

Будет обработано населенных пунктов: 37 из 37. Лимит: 200.

это значит:

- найдено 37 подходящих населенных пунктов;
- лимит пользователя позволяет обработать до 200;
- поэтому программа обработает все 37.

Если было бы найдено, например, 450, а лимит стоял 200, программа обработала бы
только первые 200.


Что такое population_cache.json
===============================

Рядом с данными Geofabrik программа может создавать файл:

population_cache.json

Он нужен для ускорения повторных запусков.

Если программа уже нашла население для какого-то населенного пункта раньше,
при следующем запуске она сначала посмотрит туда, а не будет снова делать запрос
в интернет.


Зачем нужен лимит населенных пунктов
====================================

Для крупных городов и больших зон, например Москвы, населенных пунктов может быть
много. Если обрабатывать все подряд, нагрузка на комп или ноут будет выше и работа
может идти дольше.

Поэтому в программе есть поле:

"Обработать пунктов, максимум"

Оно ограничивает, сколько населенных пунктов программа будет реально обогащать
населением за один запуск второго шага.


Зачем нужны опции точности
==========================

"Оставлять только автомобильные классы дорог" - убирает пешеходные, велосипедные,
служебные и другие неподходящие дороги, чтобы результат был ближе к реальной поездке
на автомобиле.

"Учитывать односторонние дороги" - использует поле oneway, если оно есть в данных.
Это важно в городах и на развязках, где нельзя ехать в любую сторону.

"Показывать достижимые дороги линиями" - рисует на карте сами дороги, до которых
можно доехать.

"Показывать тепловую карту узлов" - добавляет цветную подсветку плотности достижимых
точек дорожной сети.


Почему иногда старт переносится на ближайшую автосеть
=====================================================

В OpenStreetMap рядом с заданной точкой может оказаться маленький изолированный
кусок дороги: парковка, подъезд, закрытый проезд или ошибочный обрывок линии.

Если программа видит, что ближайшая дорога изолирована и не связана с нормальной
автосетью, она ищет рядом ближайший связанный участок дорог. Это нужно, чтобы
результат отвечал задаче "куда реально можно доехать на авто".


Что программа не делает
=======================

Программа не строит маршрут между двумя городами.
Программа не сравнивает несколько городов между собой.
Программа не строит единую подробную карту всей России.
Программа не заменяет навигатор.
